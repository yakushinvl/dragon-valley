# 🐉 Драконья Долина — фиджитал-игра для детей

## Идея и ценность

### Проблема
Современные родители сталкиваются с чрезмерным использованием экранов детьми. 80% родителей хотели бы качественного офлайн‑досуга для своих детей, но им не хватает инструментов, которые бы увлекательно сочетали экранное время с реальной деятельностью. Особенно востребованы творчество, чтение и физическая активность.

### Решение
«Драконья Долина» — это **фиджитал‑игра** (digital + physical), где ребёнок:
- получает в игре задание (например, найти 5 круглых предметов дома, прочитать страницу сказки или попрыгать на одной ноге);
- **выполняет его в реальном мире** без экрана;
- возвращается к игре, решает простое математическое выражение (проверка от взрослого);
- получает награду — опыт для своего дракона.

Родитель видит прогресс по всем направлениям развития: математика, русский язык, логика, окружающий мир. Игра доказывает, что время перед экраном потрачено с пользой.

### Почему это круто
- 🎮 **Игровой цикл без экрана** — ребёнок не залипает в телефоне, а двигается, читает, изучает мир.
- 🐉 **Драконы как питомцы** — персонажи мотивируют возвращаться и выполнять задания.
- 🧠 **Развитие навыков** — каждое задание развивает конкретную область (математика, речь, логика, эрудиция).
- 👨‍👩‍👧 **Участие взрослого** — родитель не просто контролирует, а становится частью игры, помогая проверить ответ.
- 📊 **Понятный прогресс** — уровни драконов и шкала XP показывают рост ребёнка.

Проект создан в рамках **геймджема Учи.ру** и полностью соответствует техническому заданию: веб-игра с полным игровым циклом от 30 минут, проверка реальных действий через верификацию и родительский интерфейс.

## Архитектура и компоненты системы

Система построена по принципу **клиент-сервер** с простым REST API.

```
┌─────────────────┐     HTTP      ┌─────────────────────────┐
│   Браузер       │ ◄──────────►  │   Сервер (Node.js)       │
│  (Frontend)     │   (REST API)   │   - Express             │
│  - index.html   │               │   - SQLite (game.db)    │
│  - style.css    │               └─────────────────────────┘
│  - app.js       │                         │
└─────────────────┘                         │
▼
┌─────────────────┐
│  Генератор      │
│  выражений      │
│  expressions.js │
└─────────────────┘
```

### Компоненты

#### 1. Фронтенд (`/public`)
- `index.html` — структура игры: экран с драконами, попап задания, форма ввода ответа.
- `style.css` — стили в духе Учи.ру (круглые формы, яркие цвета, дружелюбные шрифты).
- `app.js` — логика клиента:
  - загрузка списка драконов и их уровней (GET `/dragons`);
  - получение задания при клике на дракона (GET `/task/:type`);
  - отправка ответа на проверку (POST `/complete`);
  - обновление прогресса и XP.

#### 2. Бэкенд (`server.js`, `routes.js`, `db.js`, `expressions.js`)
- **server.js** — запускает HTTP‑сервер Express, раздаёт статику, подключает маршруты.
- **db.js** — инициализация SQLite, создание таблиц (`dragons`, `tasks`), хелперы для чтения/записи XP.
- **routes.js** — обработка REST‑запросов:
  - `GET /dragons` → возвращает всех драконов с текущим уровнем и XP.
  - `GET /task/:type` → выдаёт случайное задание (текст) и генерирует новое математическое выражение для проверки.
  - `POST /complete` → принимает `{ type, answer }`, сверяет с выражением, при правильном ответе начисляет +30 XP, обновляет уровень.
  - `GET /progress` → суммарный прогресс (не используется в MVP, но полезно для родителя).
- **expressions.js** — генерирует случайные выражения вида `a + b × c`, `a + b`, `a − b` (в пределах чисел 1–10). Сохраняет правильный ответ в сессии (в реальном проекте нужно хранить на сервере для каждого типа дракона). В текущей реализации выражение генерируется при запросе задания и ожидается при проверке.

#### 3. База данных (SQLite)
Файл `game.db` создаётся автоматически. Таблицы:
- `dragons` — id, type (math/russian/logic/world), xp, level.
- `tasks` — id, type, description (текст задания для реального выполнения).

При первом запуске база заполняется стартовыми драконами (XP=0, уровень=1) и примерами заданий для каждого типа.

### Способ взаимодействия

**Типичный сценарий:**
1. Ребёнок нажимает на дракона → фронтенд вызывает `GET /task/:type`.
2. Сервер берёт случайное задание из БД и генерирует выражение (например, `3 + 4 × 2`).
3. Сервер сохраняет выражение и правильный ответ в памяти (в реальном проекте — привязав к сессии или типу дракона).
4. Фронтенд показывает задание и выражение. Ребёнок выполняет реальное действие, затем просит взрослого вычислить выражение.
5. Взрослый вводит ответ → фронтенд отправляет `POST /complete` с типом дракона и ответом.
6. Сервер сравнивает ответ с сохранённым. Если верно:
   - обновляет XP дракона (+30);
   - пересчитывает уровень по формуле (100 XP → уровень 2, 200 → 3, …);
   - возвращает `{ success: true, newXp, newLevel }`.
7. Фронтенд обновляет шкалу XP и поздравляет ребёнка.

## Как запустить проект

### Требования
- **Node.js** версии 16 или выше ([скачать](https://nodejs.org/))
- npm (устанавливается вместе с Node.js)

### Пошаговая инструкция

1. **Скопируйте папку проекта**  
   Положите папку `dragon-meadow` в удобное место.

2. **Откройте терминал в папке проекта**  
   - Windows: `cd C:\Users\Имя\dragon-meadow`  
   - macOS/Linux: `cd /Users/Имя/dragon-meadow`

3. **Установите зависимости** (выполняется один раз)  
   ```bash
   npm install
   ```

4. **Запустите сервер**
   ```bash
   npm start
   ```  
   Вы увидите:
   ```
   📦 Инициализация базы данных…
     ✓ Драконы созданы
     ✓ Задания загружены
   🐉 Драконья Долина запущена!
      👉  http://localhost:3000
   ```

5. **Откройте игру** в браузере:  
   `http://localhost:3000`

### Остановка сервера
Нажмите `Ctrl + C` в терминале.

### Сброс прогресса
Удалите файл `game.db` в корне проекта и перезапустите сервер.

## Игровой процесс (кратко)

- На главном экране — 4 дракона (математика, русский язык, логика, природа).
- Нажмите на дракона → получите задание для выполнения в реальном мире.
- Выполните задание (например, «найди 3 предмета красного цвета», «прочитай стишок», «попрыгай 10 раз»).
- Попросите взрослого вычислить простое выражение (`3 + 4 × 2 = ?`).
- Введите ответ → получите +30 XP.
- Каждые 100 XP повышают уровень дракона (максимум — 5 уровень).

- Игра доказывает: время перед экраном потрачено на развитие.
