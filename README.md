# 🐉 Драконья Долина — MVP

Фиджитал-игра для детей 6–11 лет. Ребёнок получает задание, выполняет его в жизни,
затем взрослый вычисляет выражение — и дракон получает опыт.

---

## Структура проекта

```
dragon-meadow/
│
├── server.js              ← точка входа (Express)
├── package.json
│
├── src/
│   ├── db.js              ← инициализация SQLite + хелперы запросов
│   ├── routes.js          ← все API-маршруты
│   └── expressions.js     ← генератор математических выражений
│
└── public/                ← фронтенд (отдаётся как статика)
    ├── index.html
    ├── style.css
    └── app.js
```

---

## Требования

- [Node.js](https://nodejs.org/) версии **16 или выше**
- npm (поставляется вместе с Node.js)

Проверить версию: `node -v`

---

## Запуск — шаг за шагом

### 1. Скопируй папку проекта

Положи папку `dragon-meadow` в любое удобное место, например:
```
C:\Users\Имя\dragon-meadow        (Windows)
/Users/Имя/dragon-meadow           (macOS)
/home/Имя/dragon-meadow            (Linux)
```

### 2. Открой терминал в папке проекта

**Windows:** Нажми `Win + R` → напиши `cmd` → `cd C:\Users\Имя\dragon-meadow`
**macOS/Linux:** Открой Терминал → `cd /Users/Имя/dragon-meadow`

Или просто: открой папку в проводнике, кликни правой кнопкой → «Открыть терминал здесь».

### 3. Установи зависимости

```bash
npm install
```

Это создаст папку `node_modules` со всеми библиотеками (Express, SQLite).
Выполняется только один раз.

### 4. Запусти сервер

```bash
npm start
```

В терминале появится:
```
📦 Инициализация базы данных…
  ✓ Драконы созданы
  ✓ Задания загружены

🐉 Драконья Долина запущена!
   👉  http://localhost:3000
```

### 5. Открой игру

Открой браузер и перейди по адресу:

```
http://localhost:3000
```

Готово! 🎉

## Игровой процесс

1. На главном экране — 4 дракона (математика, русский, логика, природа)
2. Нажми на дракона → получи задание для реального выполнения
3. Выполни задание (прогулка, поиск предметов, чтение и т.д.)
4. Попроси взрослого вычислить выражение (например: `3 + 4 × 2 = 11`)
5. Введи ответ → получи XP!

---

## Правила уровней

| XP накоплено | Уровень |
|:---:|:---:|
| 0–99   | 1 |
| 100    | 2 |
| 200    | 3 |
| 300    | 4 |
| 400    | 5 (максимум) |

Каждое правильное задание даёт **+30 XP**.
При неверном ответе можно попробовать снова — XP не тратятся.

## API (для разработчиков)

| Метод | Путь            | Описание                           |
|-------|-----------------|-------------------------------------|
| GET   | `/dragons`      | Список всех драконов с уровнями     |
| GET   | `/task/:type`   | Случайное задание + выражение       |
| POST  | `/complete`     | Проверить ответ, начислить XP       |
| GET   | `/progress`     | Сумма уровней всех драконов         |

Типы (`type`): `math`, `russian`, `logic`, `world`

Пример запроса к `/complete`:
```json
{ "type": "math", "answer": 11 }
```

## Возможные проблемы

**Ошибка `node: command not found`**
→ Установи Node.js с сайта https://nodejs.org (кнопка LTS)

**Порт 3000 занят**
→ В `server.js` измени строку `const PORT = 3000;` на другой номер, например `3001`

**Страница не загружается**
→ Убедись, что терминал с `npm start` открыт и не закрыт
